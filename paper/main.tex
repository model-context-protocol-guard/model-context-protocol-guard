\begin{abstract}
Model Context Protocol Guard is a transparent proxy that pins MCP tool definitions, validates arguments, constrains egress, and screens untrusted tool output.
\end{abstract}
\section{Introduction}
Tool-using agents rely on MCP servers whose descriptions and outputs are untrusted input.
\section{Threat Model}
We address tool poisoning, parser confusion, data exfiltration, and control-token injection.
